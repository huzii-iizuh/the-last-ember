# THE LAST EMBER

*Even the smallest light can change the dark.*

A short 2.5D puzzle-platformer made in **Godot 4.7.2**. You are the last living flame in a dark world. Your light reveals hidden paths, shadow thorns block the way, and your **Time Pulse** freezes moving hazards. Reach the lighthouse and relight the world.

## Play
Download `TheLastEmber.exe` from the **Releases** page and double-click it (Windows 10/11, DirectX 12 GPU). If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.

**Controls:** A/D move · Space jump · Q or right-click Time Pulse · R back to last shrine · Esc pause.

## Open the project
Install [Godot 4.7.2](https://godotengine.org/download), clone this repository, open `project.godot` and press **F5**.
